# luisa_santos_PB_TP1
Projeto de Bloco_TP1 - Sistema de Agendamento da Clínica Veterinária VidaPet

## Sobre o Projeto

O Sistema de Agendamento da  Clínica Veterinária VidaPet tem como objetivo organizar o cadastro de animais e veterinários, além do agendamento e acompanhamento das consultas.  A proposta é substituir o controle manual realizado em caderno por um sistema que permita gerenciar os horários dos profissionais e reduzir problemas como agendamentos duplicados e consultas esquecidas.

## Estrutura do Repositório

docs/ — documentação do projeto.

src/ — código-fonte Java.

## Escopo desta entrega

Nesta primeira etapa, foi desenvolvido um programa inicial em Java, executado no terminal, com um menu de opções e uma funcionalidade de simulação de cadastro de animais. O cadastro solicita informações do animal e de seu tutor, realizando validações básicas dos dados informados. As demais funcionalidades previstas para o sistema, como cadastro de veterinários e gerenciamento de consultas, armazenamento de informações serão desenvolvidas nas próximas etapas.
